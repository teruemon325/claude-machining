# 付録 C チェックリスト

印刷して機械のそばに貼る、または段取り表に組み込んで使ってください。

## C-1 段取り前（図面・工程）

- [ ] 材質・熱処理・硬さを図面と現物で確認した
- [ ] データム（基準）と公差の厳しい箇所を把握した
- [ ] 面粗さ・面取り・バリ・注記を洗い出した
- [ ] 段取り回数と各段取りの基準面を決めた
- [ ] 取り代・くわえ代・捨て代を確保した素材である
- [ ] 工具リスト（T・径・刃長・突き出し・ホルダ・H/D）を作成した
- [ ] 荒／仕上げの工具を分けた
- [ ] クランプと工具経路の干渉を CAM で確認した
- [ ] 不明点は設計者に確認した

## C-2 工具準備

- [ ] ホルダ・コレット・主軸テーパを清掃した
- [ ] 工具を規定トルクで締めた（対角に均等）
- [ ] 振れを工具先端で測定した（仕上げ 5 µm、荒 10 µm 以内）
- [ ] 突き出し長を工具リストに記録した
- [ ] 工具長 H・径 D を測定・登録した（T = H = D）
- [ ] マガジンの T 番号と工具リストを照合した
- [ ] 工具の摩耗・欠けを目視した（新品／再研磨の区別）

## C-3 段取り・原点出し

- [ ] テーブル・バイス・治具の基準面を清掃した
- [ ] 治具／バイスの平行をダイヤルで確認した（0.01/100）
- [ ] ワークの浮きがない（パラレルが動かない）
- [ ] くわえ代 5 mm 以上、クランプは支持点の上
- [ ] クランプ力を一定にした（トルク・圧力）
- [ ] G54〜G59 をクリアしてから入力した
- [ ] X・Y・Z の原点を入力し、MDI で移動して目視確認した
- [ ] センサ径・スタイラス径の補正を忘れていない
- [ ] 段取り写真を撮った

## C-4 空運転・初品

- [ ] プログラムの頭（G17 G21 G40 G49 G54 G80 G90）を確認した
- [ ] 各工具の最初の Z 移動に G43 H_ がある
- [ ] 安全高さ・R 点がクランプより上
- [ ] Z+50 または送り 25%・シングルブロックでドライランした
- [ ] 工具交換位置・退避で干渉しない
- [ ] 初品は工具ごとに M01 で止め、切りくず・音・負荷を確認した
- [ ] 仕上げ前に中間測定し、D/H/G54 を補正した
- [ ] 初品の全寸法・面粗さ・バリを検査・記録した
- [ ] 補正値と最終条件を条件表に記録した

## C-5 工具交換時（寿命管理）

- [ ] 交換基準（個数／時間／VB）に達した
- [ ] 刃先をルーペで観察し、摩耗の種類を記録した
- [ ] 切りくずの色・形を確認した
- [ ] 新工具の振れ・長さを再測定した
- [ ] 交換後の初品を測定した
- [ ] 異常摩耗なら原因（材料・クーラント・条件・振れ）を確認した

## C-6 日常点検（始業）

- [ ] 潤滑油・作動油の量、エア圧
- [ ] クーラントの量・濃度・臭い・浮上油
- [ ] 暖機運転（主軸・各軸）
- [ ] 主軸テーパ・ホルダの清掃
- [ ] 異音・振動・アラーム履歴
- [ ] ドアインターロック・非常停止の動作
- [ ] テーブル・T 溝・基準面の切りくず
- [ ] 保護メガネ・安全靴・帽子、手袋なし

## C-7 日常点検（終業）

- [ ] 切りくず除去（テーブル・カバー・コンベア）
- [ ] 摺動面・テーブルのクーラント拭き取り
- [ ] 主軸を上げ、テーブルを中央に
- [ ] 気になった異常のメモ
- [ ] 加工済みワークの防錆・保管

## C-8 週次・月次

- [ ] クーラント濃度（屈折計）・pH 測定、浮上油除去
- [ ] フィルタ・ストレーナ・電装盤フィルタ清掃
- [ ] ATC マガジン・アームの清掃
- [ ] テレスコカバー・ワイパの破損確認
- [ ] 主軸振れ（テストバー）
- [ ] パラメータ・オフセット・プログラムのバックアップ
- [ ] 保守記録の更新

## C-9 びびりが出たとき

- [ ] 振れを測った
- [ ] 突き出しを最短にした
- [ ] ホルダを見直した（コレット → 焼きばめ／ミーリングチャック）
- [ ] クランプ・治具の緩み・浮きを確認した
- [ ] 工具の摩耗を確認した
- [ ] 回転数を ±10〜15% 振った／周波数から候補を計算した
- [ ] fz を薄化補正して上げた
- [ ] ap・ae を下げた
- [ ] 不等分割工具・刃数変更を試した
- [ ] ワークの支持を追加した
