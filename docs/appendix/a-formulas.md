# 付録 A 計算式集

## 1. 回転数・送り

| 項目 | 式 | 単位 |
|---|---|---|
| 主軸回転数 | n = 1000 × Vc ÷ (π × D) | min⁻¹ |
| 切削速度 | Vc = π × D × n ÷ 1000 | m/min |
| 送り速度（フライス） | Vf = fz × z × n | mm/min |
| 送り速度（ドリル・リーマ） | Vf = f × n | mm/min |
| 1 回転送り | f = fz × z | mm/rev |
| タップ送り | Vf = P（ピッチ） × n | mm/min |
| 切りくず除去量 | Q = ap × ae × Vf ÷ 1000 | cm³/min |
| 穴あけ除去量 | Q = π × D² ÷ 4 × f × n ÷ 1000 | cm³/min |

**早見（n の目安、Vc = 100 m/min）**：φ3 → 10,600、φ6 → 5,300、φ10 → 3,200、φ16 → 2,000、φ20 → 1,600、φ50 → 640、φ100 → 320

## 2. 切りくず薄化補正

fz' = fz ÷ √(1 − (1 − 2·ae/D)²)

| ae/D | 5% | 10% | 15% | 20% | 30% | 40% | 50% |
|---|---|---|---|---|---|---|---|
| 係数 | 2.29 | 1.67 | 1.40 | 1.25 | 1.09 | 1.02 | 1.00 |

ボールエンドミルの実効径（切込み ap のとき）：D_eff = 2 × √(ap × (D − ap))。Vc はこの径で計算する。

## 3. 所要動力

Pc = Q × Kc ÷ (60 × 10³ × η) [kW]
（Q [cm³/min]、Kc：比切削抵抗 [MPa = N/mm²]、η：機械効率 0.7〜0.85）

| 材料 | Kc（fz 0.1 付近の目安）[MPa] |
|---|---|
| アルミ合金 | 700〜900 |
| 黄銅 | 900〜1,200 |
| 鋳鉄 FC | 1,000〜1,400 |
| 炭素鋼 S45C | 1,800〜2,400 |
| 合金鋼 SCM | 2,200〜2,800 |
| SUS304 | 2,400〜3,000 |
| Ti 合金 | 2,000〜2,600 |
| Ni 基耐熱合金 | 3,000〜4,000 |

**例**：S45C、Q = 50 cm³/min、Kc = 2,000、η = 0.8 → Pc = 50 × 2000 ÷ (60,000 × 0.8) ≈ 2.1 kW

## 4. 面粗さ

| 項目 | 式 |
|---|---|
| 送りマーク理論粗さ | Rz ≈ f² ÷ (8 × R) × 1000 [µm]（f [mm]、R：ノーズ R [mm]） |
| ボールのスカラップ高さ | h ≈ ae² ÷ (4 × D) × 1000 [µm] |
| Ra と Rz | Ra ≈ Rz ÷ 4（切削面の目安） |
| 必要 f（Rz 目標から） | f = √(8 × R × Rz ÷ 1000) |
| 必要ピック（h 目標から） | ae = √(4 × D × h ÷ 1000) |

## 5. 工具寿命（テイラー）

Vc × Tⁿ = C

寿命比：T₂/T₁ = (Vc₁/Vc₂)^(1/n)

| n | Vc +10% | Vc +20% | Vc −10% | Vc −20% |
|---|---|---|---|---|
| 0.15（ハイス） | 0.53 | 0.30 | 2.0 | 4.4 |
| 0.25（超硬） | 0.68 | 0.48 | 1.5 | 2.4 |
| 0.4（セラミック） | 0.79 | 0.63 | 1.3 | 1.7 |

## 6. 工具のたわみ

δ = F × L³ ÷ (3 × E × I)、I = π × D⁴ ÷ 64

| 変更 | たわみの倍率 |
|---|---|
| L を 2 倍 | 8 倍 |
| L を 1.5 倍 | 3.4 倍 |
| D を 0.8 倍 | 2.4 倍 |
| D を 0.5 倍 | 16 倍 |
| ハイス → 超硬 | 約 1/3 |

## 8. びびり（安定回転数）

n = 60 × f ÷ (z × k)　（f：びびり周波数 [Hz]、z：刃数、k = 1, 2, 3…）

面のびびり縞ピッチ p [mm] から周波数を推定：f ≈ Vf ÷ (60 × p)

## 9. 穴・ねじ

| 項目 | 式・目安 |
|---|---|
| メートル並目ねじの下穴径（切削タップ、約 75% 山） | d − P（例 M6×1 → φ5.0、M8×1.25 → φ6.8、M10×1.5 → φ8.5、M12×1.75 → φ10.2） |
| 転造タップの下穴径 | 約 d − 0.45 P（M6 → φ5.55、M8 → φ7.45、M10 → φ9.3。メーカー表を優先） |
| ドリル送りの目安 | f ≈ 0.01〜0.02 × D（超硬は 0.015〜0.03 × D） |
| ペック量 Q（G83） | 1〜3 × D |
| リーマ取り代（径） | 0.1〜0.3 mm（φ10 以下は 0.1〜0.2） |
| ヘリカル補間の最小径 | 工具径 × 1.2 以上（中心の削り残し回避） |

## 10. 円弧・座標

| 項目 | 式 |
|---|---|
| 円周上の点 | X = R × cos θ、Y = R × sin θ |
| 弦の長さ | c = 2 × R × sin(θ/2) |
| 面取り C の 45° 移動 | X と Y に同じ C を加減 |
| G02/G03 の I, J | 始点から円弧中心への相対距離（I = Xc − Xs、J = Yc − Ys） |
| 多角形化の許容誤差 | 円弧を弦で近似する誤差 e = R × (1 − cos(θ/2)) |
