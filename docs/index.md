# マシニングセンタ加工ノウハウ集

製造業の切削加工、特に **マシニングセンタ（MC）** を使った加工の現場ノウハウを、図とともに体系的にまとめたものです。
新人教育、加工条件の見直し、トラブル対応の「まず何を疑うか」の手引きとして使えるようにしています。

> **使い方のヒント**
> - 初めての方は「[加工準備の進め方](00-preparation.md)」→「[切削条件](04-cutting-conditions.md)」→「[段取り・治具・クランプ](05-setup-fixture.md)」の順に読むと全体像がつかめます。
> - トラブルが起きたら「[付録 B トラブルシューティング早見表](appendix/b-troubleshooting.md)」から症状で引いてください。
> - 数値はすべて「目安」です。必ず工具メーカーのカタログ推奨値と自社の機械・治具の剛性を起点に調整してください。

## 切削シミュレータ

`docs/app/cutting-simulator.html` は、材料・工具・切削条件・機械仕様を入力すると、回転数・送り・除去量・所要動力・切りくず厚さ・簡易安定限界を計算し、エンドミル側面加工の様子を上面図のアニメーションで再生する単体の HTML アプリです。ブラウザで開くだけで動作します（サーバー不要）。プリセット（アルミ荒加工、S45C 側面荒、壁仕上げ、SUS304 トロコイド、びびりの例、擦りの例）を切り替えると、条件の違いが切りくずの形・色、たわみ、判定にどう表れるかを比べられます。[04 切削条件](04-cutting-conditions.md) の式をそのまま使っています。

## この資料の考え方

1. **準備が 7 割**：マシニング加工の品質と能率は、図面の読み込み・工程設計・段取りでほぼ決まります。
2. **剛性が全て**：機械・ホルダ・工具・治具・ワークの「弱いところ」が加工の限界を決めます。びびり、寸法不良、工具欠損はたいてい剛性不足が根にあります。
3. **切りくずを見る**：切りくずは無料の加工状態センサです。色・形・厚さから、条件が合っているかを読みます。
4. **記録して再現する**：条件表・段取り写真・プログラム・補正値をセットで残し、次回は「同じ手順」で再現できるようにします。
5. **安全に例外なし**：ドアを閉める、手袋をしない、初品はオーバーライドを絞る。この 3 つだけは絶対に守ります。
