# マシニングセンタ加工ノウハウ集

製造業の切削加工、特に **マシニングセンタ（MC）** の現場ノウハウを蓄積・検索・共有するためのリポジトリです。3 つの部品で構成しています。

| 部品 | 場所 | 内容 |
|---|---|---|
| **ノウハウ集アプリ**（マシニング加工ノウハウ集） | `/`（`src/`） | カード形式で検索・絞り込み・追加・編集・削除・画像添付ができる Web アプリ。初期データ 42 件を収録 |
| **解説ドキュメント**（マシニングセンタ加工 解説ドキュメント） | `/docs/` | 全 14 章＋付録 4 本の Markdown。図版 27 点（SVG）付き。MkDocs でサイト化 |
| **切削シミュレータ** | `/simulator/`（`docs/app/`） | 切削条件を入力すると計算結果・判定と加工アニメーション（2D／3D）を表示 |
| **G コードトレーナー** | `/gcode/`（`docs/app/`） | G コードを書いて経路を確認しながら学べる。シミュレータ・レッスン 9 本・リファレンス・クイズ・自動判定つき課題 5 問 |

GitHub Pages に配信すると、`/` にアプリ、`/docs/` にドキュメント、`/simulator/` にシミュレータ、`/gcode/` に G コードトレーナーが並びます（アプリの「…」メニューからも開けます）。

## ノウハウ集アプリの機能

- **ノウハウの登録・編集・削除**：「現象・課題」「原因」「対策・ノウハウ」「備考」の 4 項目で構造化して記録
- **カテゴリ分類**：工具・切削条件 / 段取り・治具・クランプ / 加工精度・寸法 / びびり・振動 / 切りくず・切削油 / 工具摩耗・寿命 / 面粗さ・仕上げ / プログラム（CAM・G コード） / 機械の保守・精度管理 / 安全 / 材料 / 機械・工具の選定 / 加工準備・工程設計
- **タグ付けとタグ絞り込み**（複数タグの AND 検索）
- **全文検索**（全角・半角、大文字・小文字を区別しない。空白区切りで複数語の AND 検索）
- **画像の添付**（写真・スケッチ・図を 1 件あたり最大 20 枚。ファイル選択、ドラッグ＆ドロップ、貼り付けに対応。長辺 1600px に自動縮小）
- **お気に入り**
- **JSON エクスポート／インポート**（バックアップや他の端末との共有に。画像も含む）
- **初期データ** 42 件（解説ドキュメントの要点を抜粋。図版付き）
- スマートフォン対応のレスポンシブレイアウト

> 初期データの数値は一般的な目安です。工具メーカーの推奨値と自社の機械・治具・ワークの剛性に合わせて現場で検証・調整してください。

## 使い方

```bash
npm install
npm run dev        # 開発サーバー（http://localhost:5173）
npm test           # ユニットテスト
npm run build      # dist/ に本番ビルドを出力（シミュレータ・図版も同梱）
npm run preview    # ビルド結果をローカルで確認
```

解説ドキュメントをローカルで見る場合：

```bash
pip install mkdocs mkdocs-material
mkdocs serve       # http://127.0.0.1:8000
```

### GitHub Pages への配信

リポジトリ設定の Pages > Source を「GitHub Actions」にすると、`main` ブランチへの push で `.github/workflows/deploy-pages.yml` が動き、アプリ・ドキュメント・シミュレータをまとめて配信します。

## データについて

- 文章データはブラウザごとの localStorage（キー `machining-knowhow:v1`）、画像本体は IndexedDB（データベース名 `machining-knowhow`）に保存されます。ブラウザのデータを消すと失われるため、定期的に「JSON エクスポート」でバックアップしてください。
- インポートは既存データに統合されます。同じ ID のノウハウは上書き、それ以外は追加されます。
- 「初期データに戻す」は登録したノウハウをすべて消去します。
- チームで共有する初期データを増やしたいときは、エクスポートした JSON の内容を `src/data/seed.ts` に追記してください。図版は `docs/images/` の SVG を `src/data/seedImages.ts` から参照しています。

## 技術スタック

- React 19 + TypeScript + Vite、テスト: Vitest
- ドキュメント: Markdown + MkDocs（Material テーマ）
- シミュレータ・G コードトレーナー: 依存ライブラリなしの単体 HTML（Canvas 描画）

## ディレクトリ構成

```

src/
  App.tsx                画面全体の状態管理
  types.ts               データ型とカテゴリ定義
  store.ts               保存・読込・CRUD・インポート／エクスポート
  imageStore.ts          画像本体の保存（IndexedDB）と縮小処理
  search.ts              検索・絞り込み・集計
  data/seed.ts           初期ノウハウデータ（42 件）
  data/seedImages.ts     初期データの図版（docs/images の SVG を参照）
  components/            UI コンポーネント
  __tests__/             ユニットテスト
docs/
  index.md, 00〜13 章, appendix/   解説ドキュメント
  images/                図版（SVG 27 点）
  app/cutting-simulator.html       切削シミュレータ
  app/gcode-trainer.html           G コードトレーナー
scripts/copy-extras.mjs  ビルド後にシミュレータ・図版を dist/ へ同梱
mkdocs.yml               ドキュメントサイトの設定
.github/workflows/       CI と GitHub Pages デプロイ
```
